Inside the app

Real double-entry bookkeeping, not a demo dashboard

Everything below is implemented and working in the current build — and all of it is free.

Companies & masters

Create and alter companies, ledgers, groups, stock items, units, godowns, voucher types, stock groups and categories, cost categories and centres, and currencies.

Vouchers & inventory

Accounting vouchers, invoice entry, inventory vouchers, stable alteration, cancellation and deletion. Optional vouchers stay outside balances. Negative stock is rejected.

Statements that reconcile

Day Book, Trial Balance, ledger and group drill-downs, monthly registers, Stock Summary, bill references and outstandings, statistics and a dashboard.

Honest Balance Sheet & P&L

Derived views show the actual difference instead of inventing a balancing figure. Inventory uses moving weighted average; returns use the prevailing cost.

Bring your old books with you

Import masters and vouchers from XML with a preview and an atomic commit — no half-saved books. Multi-file bundles import dependencies first. Export back to XML, CSV or HTML.

Keyboard-fast, exact money

Familiar navigation with F2/F3, F4–F10, Alt+G and Ctrl+A. Amounts are stored exactly and summed as integers, never as floating-point guesses.

Yours, privately

Books live in a local SQLite file with committed snapshots. Full JSON backup and restore, with a preview before anything is overwritten. No telemetry, no remote database, no sign-in.

Print & share

Dedicated voucher and report printing, real report exports, and a clickable calendar date picker alongside typed date fields.

Straight talk about the limits

This is an independent accounting engine, not a clone of any commercial package, and it does not read other vendors' proprietary data files. GST return filing, e-invoice and e-way bills, payroll, TDS/TCS, multi-currency conversion, connected banking, FIFO or batch valuation, price levels, and manufacturing/BOM are not implemented yet. Migration uses open XML exports. We would rather tell you that up front than let you discover it after installing.

Questions

The things people ask before installing

Is it really free? What is the catch?

It is free. No licence fee, no subscription, no seat limit, no per-company charge, and no feature held behind a paywall. The optional business automation tools are a separate, paid service we build with you — if you never ask for one, you never pay anything.

Is my accounting data sent anywhere?

No. Books are stored in a local SQLite file on your PC, the app server listens only on 127.0.0.1, and the build ships with no telemetry, no sign-in, no AI provider and no remote database. If you never run an automation tool, nothing leaves your machine.

Do I need internet to use it?

No. The desktop app works fully offline and bundles its own runtime, so nothing else needs installing and nothing needs to phone home.

Can I move my books from my current software?

Yes, through open XML. Export your masters and vouchers from your current system, then use Import → Preview in Independent Books, select the related files together, review the counts and warnings, and commit. Import compatibility with every vendor's schema has not been verified against every configuration — so test on a copy first.

What happens to my books if I reinstall?

Installed builds keep your database in your local app data folder, so reinstalling or updating the application does not wipe your company. Data → Backup exports every company to a validated, portable JSON file you can restore later.

Why does Windows warn me when I install it?

The installer is not code-signed, so SmartScreen shows an unknown publisher warning. That is a signing certificate we have not bought, not a sign of anything wrong with your books.

How do the automation tools get my data?

Only how you choose. Most setups read a copy of your backup file, a bank statement export, or a watched folder — and every automation writes drafts for you to approve. Mail us and we will describe the exact data path before anything starts.

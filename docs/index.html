The Anti-Subscription Manifesto

Why the World Needs Independent Books

Double-entry bookkeeping was codified by Luca Pacioli in 1494. It is a universal mathematical discipline — not a corporate rent-seeking scheme.

Your Data Is Yours Forever

Cloud accounting platforms store your company's deepest secrets on multi-tenant servers. If you ever cancel your subscription, they freeze your account and lock you out of your historical records. With Independent Books, your database is a single, standard SQLite file on your physical hard drive.

Keyboard Speed at 120 WPM

Modern web apps force you to take your hands off the keyboard, wait for spinning loaders, and click tiny buttons with a mouse. Independent Books preserves every authentic Tally Prime muscle-memory hotkey (F2–F10, Alt+G, Ctrl+A) so your accountants can post hundreds of invoices an hour without touching a mouse.

Zero Mathematical Guesswork

Most modern JavaScript and SaaS web tools calculate money using standard IEEE floating-point math, leading to tiny rounding errors that accumulate and corrupt balance sheets. Independent Books computes every voucher using exact Python Decimal and integer cents. Zero balancing plugs. Zero fabricated numbers.

Frequently Asked Questions

Everything You Need to Know

Is Independent Books really 100% free forever?

Yes. Independent Books is released under the permissive open-source MIT License. There are no renewal fees, no subscription plans, no locked screens, no seat limits, and no company limits. You are free to use it for personal, business, or client bookkeeping.

Where is my accounting database stored on my computer?

Your books are stored in a local SQLite file (data/books.sqlite3) on your own machine. The backend server strictly listens on the loopback address 127.0.0.1 and has zero external telemetry or cloud sync. You can take full JSON backups anytime via Data → Backup.

How do I delete a company I no longer need?

Press Alt+K (or F3) → select Alter Company. In the Company Alteration screen, press Alt+D (or click the red Delete Company button). A two-step safety confirmation dialog will prompt you to confirm permanent deletion.

Can I import existing company ledgers from Tally Prime?

Yes! Export your masters and vouchers from Tally as standard XML. Then in Independent Books, choose Import → Import XML, select your exported XML file, preview the transaction counts, and commit.

Can I run Independent Books on macOS or Linux?

Yes! For macOS, an official launcher script (launch_mac.sh) is included in the GitHub repository that isolates application data in ~/Library/Application Support/IndependentBooks. For Linux, you can run the server directly with Python 3.9+.
